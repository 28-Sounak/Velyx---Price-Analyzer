Velyx
Intelligent Multi-Site Product Price Analyzer

Velyx is a smart price comparison platform that collects product prices from multiple e-commerce websites and helps users find the best deal instantly.

The system fetches product information from different online stores, compares prices, tracks price history, and provides intelligent shopping insights.

Features
Multi-site product price comparison
Real-time price tracking
Product search across platforms
Price history monitoring
Smart product matching
Discount analysis
Wishlist and price alerts
Responsive modern UI
